# augment-ux-test

UX audit of the new 02_set/augment.py pipeline. Goal: identify friction points before it gets
used in real experiments.

## What was tested

- `augment_set()` with NoiseSpec and VolumeSpec on the `lite` set, yamnet embedder
- `CombineSpec` with ins_buzz_Halyomorpha + ambient_background
- Caching behavior (overwrite=False)
- Training via `03_train/main.py --augment`
- New CLI for `02_set/augment.py`
- New `--augment` passthrough in root `main.py`

## Friction points found and fixed

**setup_worktree.sh missing audio symlink.**
Augmentation reads raw audio from `dir_audio()`, but the worktree setup only symlinked
`embeddings/`, not `audio/`. Running augment from a worktree raised FileNotFoundError.
Fix: loop over `[embeddings, audio]` in the symlink block. Committed to main.

**02_set/augment.py: no CLI, hardcoded to 'standard' set.**
The `__main__` block had `setname='standard'` and specific specs hardcoded with no
argparse. Fix: added `--set`, `--embedder`, `--fold`, `--overwrite` args; moved the
default specs to `DEFAULT_SPECS` constant at module level. Committed to main.

**02_set/augment.py: `import config as cfg` fails when run as script.**
The sys.path setup was inside `__main__`, but `import config` is at module level, so it
ran before the path was fixed. Fix: moved `sys.path.insert` calls to module level (same
pattern as 02_set/main.py). Committed to main.

**Root main.py had no --augment passthrough.**
Running the full pipeline via root `main.py` had no way to pass augmented dirs to
training. Fix: added `--augment aug_dirname...` arg that flows through to `train_model`.
Committed to main.

## Remaining friction (not fixed)

**Uncommitted changes don't transfer to worktrees.**
At the time of this test, augment.py and augment_specs.py were untracked, and
config.py/03_train/main.py/train.py/dataset.py had uncommitted augmentation-related
changes. None of these were in the worktree. Had to manually copy each file. The fix is
simply: commit the feature before creating the worktree. But this bit us and is worth
knowing about.

**--augment takes dirname strings, not specs.**
`03_train/main.py --augment augment_noise_0.05 augment_volume_2.5` requires knowing the
exact directory name generated by spec_dirname(). If the float is slightly different
(0.050 vs 0.05), the dir won't be found. load_augmented() silently prints a warning and
skips the missing dir — no error. Consider adding a validation pass that errors on
unknown augment dirs, or a `--augment-spec` alias that auto-derives the dirname.

**Verbose per-file logging.**
581 files × 5 specs = 2905 log lines for a routine run. Noisy. The per-file messages are
useful for debugging (e.g. confirming the right files are matched by labels filter) but
excessive for normal use. A progress counter or quiet-by-default with -v flag would help.

**CombineSpec: silent failure on label mismatch.**
If class_source or class_augment don't match any audio files, the function prints
"no source frames for X" and returns silently. Easy to mistake for success. Should be
a warning (or error with --strict).

**All CombineSpecs share one output directory.**
Multiple CombineSpec objects all write into augment_combine/. Training with
--augment augment_combine includes ALL combine pairs, with no way to include some but not
others. Probably fine in practice but worth knowing.

## Results

Caching works correctly — second run with overwrite=False skipped 273 already-done
files. Augmented embeddings are written via the embeddings/ symlink, so they persist in
the main tree and are immediately reusable across worktrees.

Training with --augment augment_noise_0.05 augment_volume_2.5 loaded successfully and
trained without errors. CombineSpec output also loaded correctly via augment_combine.
