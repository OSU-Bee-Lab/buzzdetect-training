## Setup steps

1. **Repoint the `audio` symlink.** It is tracked and currently dangles at
   `/Volumes/Expansion/audio_bee_detection/experiments`. Replace it:
   ```
   cd buzzdetect-training
   rm audio && ln -s /path/to/your/source/audio audio
   ```
   `config.TRAIN_DIR_AUDIO` is just `<root>/audio`; stage 2 reads
   `<audio>/<ident>.*` per ident listed in `medium/annotations.csv`.
   (`git update-index --skip-worktree audio` if you want to keep the symlink
   change out of git.)

2. **Conda env** from `environment.yml`:
   ```
   conda env create -f environment.yml   # creates 'buzzdetect-train'
   ```

3. **Sanity check** the ident paths resolve: the first column logic in
   `02_set/extract.py::get_ident_audio_path` globs `<audio>/<ident>.*`. If your
   source tree is laid out differently than the laptop's, snips will be skipped
   with a warning — fix the symlink target depth so `<audio>/<ident>` lines up.

## Run

From the project root (paths resolve relative to cwd):

```
conda run -n buzzdetect-train python main.py \
  --model test_medium_rebuild \
  --set medium \
  --embedder yamnet \
  --workers 8 \
  --yes
```

This runs stage 2 (snip → framed cache → embeddings) then stage 3
(leave-one-fold-out CV + shipped model). `config_extract.json` in the set dir
(`overlap_event_prop=0.2`, `framehop_prop=1`) wins over CLI params — the set is
pinned to it.

Outputs land in `models/test_medium_rebuild/`; the metrics summary is
`folds_sx.csv`. Reruns resume (folds with a `config_model.json` are skipped).

### GPU run recipe for this machine

The 4 GB GTX 1650 cannot host multiple extraction workers, and YAMNet's
default 300-frame batch alone overflows it. Run stage 2 as:

```
BUZZDETECT_CHUNK_FRAMES=48 TF_FORCE_GPU_ALLOW_GROWTH=true \
TF_GPU_ALLOCATOR=cuda_malloc_async \
conda run --no-capture-output -n buzzdetect-train python -u main.py \
  --model <name> --set <set> --embedder yamnet --workers 1 --yes
```

Stage 3 (single process) is fine with these same env vars. On a bigger GPU,
drop `BUZZDETECT_CHUNK_FRAMES` and raise `--workers`.
